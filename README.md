# Easwanth — Integration Engineering Portfolio

A performance-first Next.js portfolio focused on MuleSoft, Salesforce, and
enterprise integration delivery.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Portfolio content is maintained in `src/data/portfolio.ts`; no database or
backend is required.
